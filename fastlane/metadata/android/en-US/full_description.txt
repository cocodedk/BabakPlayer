BabakPlayer is a companion app for BabakCast. It imports media parts shared from other apps, such as WhatsApp, and plays them back in the order they were received, as one continuous playlist.

It supports common audio and video formats, including mp3, mp4, mkv, mov, and webm. If a file fails to decode, it is marked as failed and skipped so playback continues with the rest of the queue.

The interface is available in English and Persian, with the Persian layout running right-to-left automatically.

All imported files are stored locally in app-private storage. Deleting a file or playlist removes the underlying files permanently. The app works entirely offline, with no account, cloud sync, or backend service.
